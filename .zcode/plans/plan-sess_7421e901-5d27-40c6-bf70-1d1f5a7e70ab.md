**Use case (locked):** Shadow IT & Governance Tracker — maps Identities → Groups → Resources to expose recursive "toxic access" (a **suspended external consultant still holding an ADMIN path to the customer PII database** via nested group inheritance).

**Stack:** CognoDB (bolt+s) · **Java 17 + Spring Boot 3** (official `neo4j-java-driver`, raw parameterized Cypher — no ORM abstraction) · Maven wrapper (no local Maven needed) · Vite + React + React Flow + Tailwind. Secrets via env vars only.

## 2. Backend key decisions

- **Raw driver, not Spring Data Neo4j** — the assignment grades explicit parameterized Cypher and multi-hop traversal; SDN would hide exactly what we're being evaluated on. Easier to defend line-by-line.
- **Resilience:** `Driver` bean built at startup; `verifyConnectivity()` failure logs a warning, app still boots. `GraphExecutor` catches `ServiceUnavailable` / `SessionExpired` → circuit breaker records failure → clean 503 `{"error": "gateway_reconnecting", ...}`. Breaker: 3 consecutive failures ⇒ OPEN, fail-fast 15s, then one probe transaction (half-open).
- **Parameterization:** every statement is a `static final` String + `Value`/map params. User input only ever enters through named `$params` — nothing else can reach the query string.
- **Indexes (Anchor 1):** SeedRunner creates uniqueness constraints on `Identity.email`, `Group.name`, `Resource.name` + range index on `Resource.sensitivity` **before** loading data.
- **Cypher set (constants in `Cypher.java`, each explained in README):**
  - `ACCESS_PATHS` — `(u:Identity {email:$email})-[:MEMBER_OF|INHERITS*1..5]->(g)-[:ACCESS]->(r:Resource)` with optional `$resource` filter; marks paths **toxic** when a Suspended identity reaches a Critical resource.
  - `BLAST_RADIUS` — `(t:Group {name:$name})-[:INHERITS*0..3]->(dg)-[:ACCESS]->(r)` → `r.name, r.sensitivity, count(dg) AS pathsAtRisk` (the SQL-awkward one).
  - `GRAPH_OVERVIEW`, `NODE_CONTEXT` (up/downstream), `SIMULATE_COMPROMISE` (reachable resource set + max exposure), `STATS` (counts + toxic-path count).
